# SPECIFICATION: Autonomous LEO-Integrated Drone Mesh Network for Mountain/Forest Disaster Response

## 1. Project Overview & Objective
Build an open-source, lightweight Multi-Agent Reinforcement Learning (MARL) simulation environment simulating a swarm of autonomous UAVs deployed in a mountainous forest disaster zone. 

The swarm must dynamically self-organize into a self-healing wireless mesh network that connects ground survivors and search-and-rescue (SAR) teams to a passing Low Earth Orbit (LEO) satellite constellation (e.g., Starlink) when terrestrial infrastructure is destroyed.

### Primary Engineering Constraints:
* **Compute:** Must run and train fast on a standard laptop CPU/GPU. Avoid heavy game engines during training.
* **Architecture:** Centralized Training with Decentralized Execution (CTDE).
* **Environment Standard:** PettingZoo `ParallelEnv` (Gymnasium-compliant multi-agent interface).

---

## 2. Tech Stack Recommendations
* **Language:** Python 3.10+
* **RL Framework:** `PettingZoo` + `PyTorch` (or `CleanRL` / `TorchRL` for clean, lightweight MAPPO/IPPO implementations).
* **Graph & Network Routing:** `NetworkX` (for shortest-path multi-hop packet routing and topology analysis).
* **Math & Physics:** `NumPy` & `SciPy` (vectorized kinematics and raycasting).
* **Telemetry Streaming (Optional Visualizer):** `FastAPI` + `WebSockets` streaming JSON state to a React/Three.js frontend.
